# CC0 面料种子库

这是一组用于 HuichuangAI 本地 Demo 的小型面料种子库。素材筛选目录来自 GitHub 上的 [`MorePET/mat-vis`](https://github.com/MorePET/mat-vis)，图片文件按目录中记录的上游来源从 ambientCG 下载。

- 许可策略：只纳入 `CC0-1.0`。
- 证据：`manifest.json` 记录来源、许可、下载地址、下载时间和标签；`licenses/CC0-1.0.txt` 保存许可证文本。
- 运行时展示：前端只加载 `*-color.jpg` 或 `*-preview.png`；其他 PBR 通道可在后续扩展。
- 重新下载：运行 `python scripts/materials/download_cc0_materials.py`。

“CC0”只描述这组公开种子素材。客户上传的私有面料、联网搜索结果和后续导入素材必须单独记录来源与许可状态。
